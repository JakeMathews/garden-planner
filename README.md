# 🌱 Mom's Seed Rating Page Generator 🌻

Generate a cute HTML page so Mom can rate your seeds and help you decide what to grow!

## How to Use

1. Go to [planter.garden](https://planter.garden) and log in
2. Open your browser console:
   - **Mac**: `Cmd + Option + J`
   - **Windows**: `F12`, then click "Console" tab
3. Copy the entire contents of `generate-rating-page-browser.js` and paste into the console
4. Press Enter — the page downloads automatically!
5. Open `seed-rating.html` and send it to Mom 💚

## What Mom Gets

- A cute dark-themed page with all your seeds organized by plant type
- 3-star rating system:
  - ⭐ = Maybe
  - ⭐⭐ = Yes please!
  - ⭐⭐⭐ = Must grow!
- Option to rate whole plant categories OR specific varieties
- "💌 Email to Favorite Son" button to send her picks
- Works on her phone!

## Features

- Ratings save automatically (localStorage)
- Per-row source dropdowns when seeds come from multiple sources
- Mobile responsive design
- Grouped report format with emojis

## Files

| File | Description |
|------|-------------|
| `generate-rating-page-browser.js` | The script to paste in your browser console |
| `seed-rating.html` | Generated rating page (after running the script) |
